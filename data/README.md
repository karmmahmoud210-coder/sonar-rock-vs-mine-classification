# Dataset

The notebook and training script retrieve the Connectionist Bench (Sonar, Mines vs. Rocks) dataset from the UCI Machine Learning Repository using `ucimlrepo` (dataset ID `151`).

The repository does not include a separate local copy of the raw dataset.

- Dataset page: https://archive.ics.uci.edu/dataset/151/connectionist%2Bbench
- DOI: https://doi.org/10.24432/C5T01Q
- License: CC BY 4.0

The dataset contains 208 observations, 60 numeric sonar measurements, and a target label of `M` (mine) or `R` (rock).
